# MoveDock 0.1.0 検証記録

検証日: 2026-09-22

## 成功した確認

- Vue / TypeScript 型チェック、本番 Vite ビルド。
- Vitest 5 件: 信頼確認、実行確認のキャンセル、二重実行防止、未保存の変更、サイト切り替え。
- Rust 6 件: 引数、環境一覧、標準出力・標準エラー・失敗終了、停止・タイムアウト、ログ秘匿、Movefile の信頼と変更検出。
- changelogen の patch / minor / major リリースを一時 Git リポジトリで実行。各バージョン、変更履歴、コミット、タグの整合性と dirty tree の拒否を確認。
- macOS Universal の .app / .dmg 作成。`lipo -archs` は `x86_64 arm64`、`codesign --verify --deep --strict` は成功。
- 実アプリの起動、設定画面、設定保存と再起動後の読み込み。
- ネイティブファイル選択から検証用 Movefile を登録。ERB の信頼確認ダイアログを表示。
- GUI から導入済み Wordmove 5.2.2 を実行し、検証用 Movefile の local / staging を取得。同期ボタンの有効化を確認。
- 実アプリから転送しない模擬 CLI を実行。シミュレーション確認、`--simulate` を含む引数、stdout / stderr の表示、正常終了、履歴の永続保存を確認。
- ブラウザ上でライト / ダークの画面と同期画面を確認。

## 未確認・制限

- 実サイトへの Push / Pull、実 DB の移行は行っていない。
- 停止は Rust の自動テストで検証済み。実画面での停止操作は macOS 自動操作が不安定だったため未完了。
- 両 CPU のバイナリを含むことは検証済みだが、別の Apple Silicon 実機での起動は未確認。
- 初回検証では Wordmove フォークの依存 gem が未導入のため直接実行モードを使用。2026-09-23 の追検証で固定された依存 gem を導入し、Bundler 経由でも `5.3.0.pre.1` の起動を確認。
- Developer ID 署名・公証は未設定。ローカル用 ad-hoc 署名を使用。

検証用サイト・実行パス・履歴は確認後に初期状態へ戻す。リモートへの転送は行っていない。
