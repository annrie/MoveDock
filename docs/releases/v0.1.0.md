## 日本語

MoveDock の初回リリースです。Wordmove CLI を Rust / Tauri 2 / Vue 3 のデスクトップ画面から操作できます。

**現在のアプリ UI は日本語です。多言語対応は次のバージョンで予定しています。**

### 主な機能

- Movefile で複数サイトを登録し、リモート環境を選択
- Push / Pull、同期対象の個別選択、実行前の確認とシミュレーション
- 実行ログの表示・選択・コピー、明示的な完了表示、実行履歴
- 大量ログをまとめて描画し、最新 2000 行を保持
- Movefile の作成・編集と外部変更の検出
- Ruby / Bundler / Wordmove の自動設定と実行環境の確認
- ライト・ダーク・システムテーマ、読みやすさを調整した文字サイズ

### ダウンロードと必要な環境

`MoveDock_0.1.0_universal.dmg` を開き、`MoveDock.app` をアプリケーションフォルダへコピーしてください。macOS 11 以降の Intel / Apple Silicon 共通です。`SHA256SUMS.txt` に DMG の SHA-256 を記載しています。

Ruby / Wordmove と、同期に必要な SSH・rsync・WP-CLI・PHP・MySQL クライアントなどは別途必要です。同梱されていません。[README の導入手順](https://github.com/annrie/MoveDock/blob/v0.1.0/README.md#日本語)を参照してください。検証済みの Wordmove フォークは [`978860b`](https://github.com/annrie/wordmove/commit/978860b302b3de0db382ac54eba6be4c711e16d7) で、Ed25519 鍵・rsync の修正を含みます。古い `v5.3.0.pre.1` タグにはこの 2 件の修正が含まれていません。

### 既知の問題・検証範囲

- 初回の環境読み込みが一度タイムアウトし、再試行で成功する事象が残っています。原因は調査中です。直近の再起動・負荷テストでは再現せず、約 4〜16 秒で成功しました。
- ad-hoc 署名を使用しています。Developer ID 署名・公証は未設定のため、macOS で起動時のセキュリティ確認が必要になる場合があります。
- Universal バイナリの Intel / Apple Silicon 両アーキテクチャと署名を検証しています。実機での起動検証は Intel Mac で実施し、別の Apple Silicon 実機では未確認です。
- 15 件のフロントエンドテスト、型チェック、本番ビルド、実アプリの環境読み込み・シミュレーションを確認済みです。同期前にバックアップを取り、まずステージング環境で確認してください。

## English

The first release of MoveDock brings a Rust / Tauri 2 / Vue 3 desktop interface to the Wordmove CLI.

**The current app UI is in Japanese. Multilingual UI support is planned for the next version.**

### Features

- Register multiple sites from Movefiles and select remote environments
- Push / Pull, individual sync targets, confirmation and simulation before syncing
- View, select and copy logs, with explicit completion status and run history
- Batch high-volume log rendering and retain the latest 2,000 lines
- Create and edit Movefiles, detecting external changes
- Automatic Ruby / Bundler / Wordmove configuration and runtime checks
- Light, dark and system themes, with improved text sizing

### Download and requirements

Open `MoveDock_0.1.0_universal.dmg` and copy `MoveDock.app` to your Applications folder. The same app supports Intel and Apple Silicon on macOS 11 or later. `SHA256SUMS.txt` contains the DMG's SHA-256 checksum.

Ruby, Wordmove and tools required by your sync method—such as SSH, rsync, WP-CLI, PHP and MySQL clients—must be installed separately. They are not bundled. See the [README setup guide](https://github.com/annrie/MoveDock/blob/v0.1.0/README.md#english). The tested Wordmove fork revision is [`978860b`](https://github.com/annrie/wordmove/commit/978860b302b3de0db382ac54eba6be4c711e16d7), which includes the Ed25519 key and rsync fixes. The older `v5.3.0.pre.1` tag does not include these two fixes.

### Known issues and verification

- An intermittent timeout on the first environment load remains unresolved; retrying has succeeded. The cause is under investigation. Recent restart and load tests did not reproduce it and completed in approximately 4–16 seconds.
- The app uses an ad-hoc signature. Developer ID signing and notarization are not configured, so macOS may require a security confirmation when opening it.
- Both Intel and Apple Silicon architectures and the app signature have been verified. Runtime checks were performed on an Intel Mac; a separate Apple Silicon Mac has not been tested.
- Verification includes 15 frontend tests, type checks, a production build, and environment loading and simulation in the native app. Back up your data and test in staging before syncing.
