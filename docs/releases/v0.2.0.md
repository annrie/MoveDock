## 日本語

MoveDock の画面と案内を、YTDown と同じ8言語に対応させました。

### 新機能

- 日本語・英語・繁体字中国語・フランス語・スペイン語・ポルトガル語（ブラジル）・ドイツ語・韓国語に対応
- 「設定 → 表示言語」で即時切り替え・保存。初回はシステム言語を検出し、未対応の場合は英語を使用
- 通知、同期前の確認、エラー案内、自動設定の説明、実行履歴の日付を選択言語に対応
- Wordmove / SSH / rsync の実行ログを原文で保持し、よくある失敗には翻訳した案内を補足
- 言語切り替え時も未保存の接続設定・Movefile・読み込み済み環境を保持
- 長い訳文が読めるよう画面の折り返しを調整

### ダウンロード

`MoveDock_0.2.0_universal.dmg` を開き、`MoveDock.app` をアプリケーションフォルダにコピーしてください。macOS 11 以降の Intel / Apple Silicon 共通です。`SHA256SUMS.txt` に DMG の SHA-256 を記載しています。

Ruby / Wordmove と各外部コマンドは別途必要です。推奨 CLI は [annrie/wordmove v5.3.0.pre.2](https://github.com/annrie/wordmove/releases/tag/v5.3.0.pre.2) です。[導入手順](https://github.com/annrie/MoveDock#日本語)を参照してください。

### 検証範囲・既知の問題

- 翻訳キー・埋め込み値、8言語の確認操作、言語保存、設定保持、ログ原文保持を自動テストで確認
- 8言語の初期画面・設定・同期・Movefile エディター・履歴を、通常幅と最小幅で表示確認
- Local.app の2サイトで確認済みの実環境同期（DB同期・ファイル Pull）は v0.1.0 時点の検証です。今回の多言語化では実サイトの同期は再実行していません
- 初回の環境読み込みが一度タイムアウトする問題は引き続き調査中です。発生時は再読み込みしてください
- ad-hoc 署名を使用しています。Developer ID 署名・公証は未設定です。起動検証は Intel Mac で行い、別の Apple Silicon 実機では未確認です

## English

MoveDock now offers its interface and guidance in the same eight languages as YTDown.

### Features

- Japanese, English, Traditional Chinese, French, Spanish, Brazilian Portuguese, German and Korean
- Instant, persistent switching under **Settings → Display language**; system language detection on first launch, with English fallback
- Localized notifications, sync confirmations, error guidance, automatic setup notes and history dates
- Original Wordmove / SSH / rsync output preserved, with translated guidance for common failures
- Unsaved connection settings, Movefile edits and loaded environments preserved when switching languages
- Wrapping adjusted to accommodate longer translations

### Download

Open `MoveDock_0.2.0_universal.dmg` and copy `MoveDock.app` to your Applications folder. The same app supports Intel and Apple Silicon on macOS 11 or later. `SHA256SUMS.txt` contains the DMG’s SHA-256 checksum.

Ruby, Wordmove and external commands must be installed separately. The recommended CLI is [annrie/wordmove v5.3.0.pre.2](https://github.com/annrie/wordmove/releases/tag/v5.3.0.pre.2). See the [setup guide](https://github.com/annrie/MoveDock#english).

### Verification and known issues

- Automated checks cover catalog keys and placeholders, confirmations in all eight languages, persistence, settings preservation and original log output
- Welcome, settings, synchronization, Movefile editor and history views checked in all eight languages at normal and minimum window widths
- Real-world DB synchronization and file pulls on two Local.app sites were verified with v0.1.0. Live site synchronization was not repeated for this localization update
- The intermittent timeout on the first environment load remains under investigation. Reload environments if it occurs
- Ad-hoc signed; Developer ID signing and notarization are not configured. Launch verification is performed on an Intel Mac; a separate Apple Silicon Mac has not been tested
